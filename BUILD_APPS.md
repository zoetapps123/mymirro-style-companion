# Quick Build Guide

## 🚀 Build Android App

```bash
npm run cap:android
```
Then in Android Studio: Click **Run** (▶️)

## 🍎 Build iOS App (Mac Only)

```bash
npm run cap:ios
```
Then in Xcode: Click **Run** (▶️)

## 🔄 After Code Changes

```bash
npm run build
npx cap sync
```

## 📦 Release Builds

**Android APK**: Build → Build APK in Android Studio
**iOS Archive**: Product → Archive in Xcode
